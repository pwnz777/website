API

A REST API for everything the workspace can do.

Predictable resource URLs, JSON bodies, standard HTTP verbs and conventional status codes. Base URL https://api.atnos.ai. HTTPS only — plaintext is refused rather than redirected, so a misconfigured client fails loudly instead of leaking a key.

Request and response

request
curl https://api.atnos.ai/v1/drafts \
  -H "Authorization: Bearer $ATNOS_API_KEY" \
  -H "ATNOS-Workspace: ws_8f21c" \
  -G -d "status=awaiting_approval"
200 OK
{

  "has_more": false,

Endpoints

MethodPathDescription
GET/v1/workspacesList workspaces available to the credential.
POST/v1/workspacesCreate a workspace and seed it from a brief.
GET/v1/connectionsList connected services and their granted scopes.
DELETE/v1/connections/:idRevoke a connection and destroy stored credentials.
GET/v1/draftsList drafts awaiting approval, filtered by agent or type.
POST/v1/drafts/:id/approveApprove a draft and release it for execution.
POST/v1/drafts/:id/rejectReject a draft with an optional reason.
GET/v1/contactsQuery contacts with lifecycle stage and source attribution.
GET/v1/reports/:idRetrieve a generated report as JSON or PDF.
GET/v1/auditPaginated, immutable audit log for a workspace.

Webhooks

Every delivery carries an HMAC-SHA256 signature in ATNOS-Signature. Verify it before trusting the payload — an unsigned webhook endpoint is an open write API. Failed deliveries retry with exponential backoff for 24 hours.

EventMeaning
draft.createdAn agent has prepared work that needs a decision.
draft.approvedA draft was approved and released for execution.
draft.rejectedA draft was rejected, with the reason if one was given.
connection.authorisedA service was connected to the workspace.
connection.revokedA connection was removed, from either side.
report.generatedA scheduled report is ready to retrieve.
agent.errorAn agent could not complete its work and stopped.
