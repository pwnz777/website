API

Una API REST para todo lo que hace el espacio de trabajo.

URLs de recurso predecibles, cuerpos JSON, verbos HTTP estándar y códigos de estado convencionales. URL base https://api.atnos.ai. Solo HTTPS: el texto plano se rechaza en lugar de redirigirse, para que un cliente mal configurado falle de forma ruidosa en vez de filtrar una clave.

Petición y respuesta

petición
curl https://api.atnos.ai/v1/drafts \
  -H "Authorization: Bearer $ATNOS_API_KEY" \
  -H "ATNOS-Workspace: ws_8f21c" \
  -G -d "status=awaiting_approval"
200 OK

Endpoints

MétodoRutaDescripción
GET/v1/workspacesLista los espacios de trabajo disponibles para la credencial.
POST/v1/workspacesCrea un espacio de trabajo y lo inicializa a partir de un brief.
GET/v1/connectionsLista los servicios conectados y los permisos concedidos.
DELETE/v1/connections/:idRevoca una conexión y destruye las credenciales guardadas.
GET/v1/draftsLista los borradores pendientes de aprobación, filtrados por agente o tipo.
POST/v1/drafts/:id/approveAprueba un borrador y lo libera para su ejecución.
POST/v1/drafts/:id/rejectRechaza un borrador, con motivo opcional.
GET/v1/contactsConsulta contactos con etapa del ciclo y atribución de origen.
GET/v1/reports/:idRecupera un informe generado en JSON o PDF.
GET/v1/auditRegistro de auditoría inmutable y paginado del espacio de trabajo.

Webhooks

Cada entrega lleva una firma HMAC-SHA256 en ATNOS-Signature. Verifícala antes de confiar en el contenido: un endpoint de webhook sin firma es una API de escritura abierta. Las entregas fallidas se reintentan con retroceso exponencial durante 24 horas.

EventoSignificado
draft.createdUn agente ha preparado trabajo que necesita una decisión.
draft.approvedUn borrador fue aprobado y liberado para ejecución.
draft.rejectedUn borrador fue rechazado, con el motivo si se indicó.
connection.authorisedSe conectó un servicio al espacio de trabajo.
connection.revokedSe eliminó una conexión, desde cualquiera de los dos lados.
report.generatedUn informe programado está listo para recuperarse.
agent.errorUn agente no pudo completar su trabajo y se detuvo.
