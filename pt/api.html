API

Uma API REST para tudo o que o workspace faz.

URLs de recurso previsíveis, corpos JSON, verbos HTTP padrão e códigos de status convencionais. URL base https://api.atnos.ai. Somente HTTPS: texto puro é recusado em vez de redirecionado, para um cliente mal configurado falhar alto em vez de vazar uma chave.

Requisição e resposta

requisição
curl https://api.atnos.ai/v1/drafts \
  -H "Authorization: Bearer $ATNOS_API_KEY" \
  -H "ATNOS-Workspace: ws_8f21c" \
  -G -d "status=awaiting_approval"

Endpoints

MétodoCaminhoDescrição
GET/v1/workspacesLista os workspaces disponíveis para a credencial.
POST/v1/workspacesCria um workspace e o inicializa a partir de um briefing.
GET/v1/connectionsLista os serviços conectados e os escopos concedidos.
DELETE/v1/connections/:idRevoga uma conexão e destrói as credenciais guardadas.
GET/v1/draftsLista os rascunhos aguardando aprovação, filtrados por agente ou tipo.
POST/v1/drafts/:id/approveAprova um rascunho e o libera para execução.
POST/v1/drafts/:id/rejectRejeita um rascunho, com motivo opcional.
GET/v1/contactsConsulta contatos com estágio do ciclo e atribuição de origem.
GET/v1/reports/:idRecupera um relatório gerado em JSON ou PDF.
GET/v1/auditLog de auditoria imutável e paginado do workspace.

Webhooks

Cada entrega leva uma assinatura HMAC-SHA256 em ATNOS-Signature. Verifique antes de confiar no conteúdo — um endpoint de webhook sem verificação é uma API de escrita aberta. Entregas que falham são reenviadas com backoff exponencial por 24 horas.

EventoSignificado
draft.createdUm agente preparou trabalho que precisa de uma decisão.
draft.approvedUm rascunho foi aprovado e liberado para execução.
draft.rejectedUm rascunho foi rejeitado, com o motivo se houver.
connection.authorisedUm serviço foi conectado ao workspace.
connection.revokedUma conexão foi removida, de qualquer um dos lados.
report.generatedUm relatório programado está pronto para ser recuperado.
agent.errorUm agente não conseguiu concluir o trabalho e parou.
